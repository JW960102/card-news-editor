# 카드뉴스 — 디자인 구현 스펙 (실측 → 코드)

> 김종욱이 피그마로 디자인 → 실측 → 이 문서에 "구현 스펙"으로 축적 → Claude가 그대로 구현.
> 새 디자인은 아래 형식대로 계속 추가. 원본 실측: 퍼스널브랜딩 repo `docs/카드뉴스_*_실측.md`.

## 변환 규칙 (공통)
- **캔버스**: 4:5. 피그마가 662×825면 → 앱은 1080×1350. **단위는 cqw**(카드폭 1%). `cqw = 피그마px ÷ 6.62`.
- **배치**: 피그마 절대좌표 그대로 → 카드 안 `position:absolute; left/top/width/height`(전부 cqw). 카드는 `container-type:inline-size`라 cqw가 카드폭 %로 스케일.
- **자간**: em으로 (px ÷ 폰트px). 대략 -0.03em, 대형은 -0.04~-0.05em.
- **폰트**: Pretendard(한글), 영문 라벨은 General Sans 가능. weight는 실측대로(Regular/SemiBold/Bold).
- **색**: 테마 토큰으로 매핑(아래).

## 테마 토큰 모델 (확장 필요)
현재 앱 토큰: `--card-bg / --card-ink / --card-sub / --card-accent / --font-*`
→ 정갈·규격형 위해 **2개 추가**:
- `--card-surface` : 안쪽 흰 카드 (예 #fcfcfa)
- `--card-neutral` : 필·노트 배경 (예 #ededed)

## THEME: sky (스카이/망고은행) — 비즈니스·프로모션 후보
상세 실측: 퍼스널브랜딩 repo `docs/카드뉴스_스카이테마_실측.md`. **6템플릿**(표지/리스트/VS/Q&A/3열/정보표).
```
--card-bg:       #3bcff7   (다크 변주 #014864)
--card-surface:  #ffffff
--card-ink:      #4b4b4b   (순검정 아님! 회색)
--card-sub:      #767676
--card-accent:   #ff86c3   (핑크 강조) / 라임 #eeff9d
--card-neutral:  #e7e7e7
```
**⚠️ 이 테마의 특수사항 (구현 시):**
- **캔버스 1:1 (824×826)** — 민트(4:5)와 다름. cqw = px÷8.24. → **앱에 비율 선택(4:5/1:1) 필요**.
- **공통 헤더 시스템**: 모든 카드 제목 = line1(Regular 34px=4.13cqw, top45=5.46cqw) + line2(ExtraBold 74.6px=9.05cqw, top89=10.8cqw), 콘텐츠 top211=25.6cqw. → **레이아웃 프리미티브로 공유**.
- **배경 2종 변주**(#3bcff7/#014864) 카드별 교대.
- **본문 검정 아님** → `--card-ink` 진회색.

## 🔨 코딩 방식 (아키텍처) — "테마 = 팩"
- **PACK** = `{ id, label, aspect(지금 4:5 고정), tokens{bg/surface/ink/sub/accent/neutral/fonts}, templates:[...] }`
- 각 팩은 **자기 템플릿을 절대배치 컴포넌트**로 가짐 (실측 그대로, **cqw 단위**, 카드 `container-type:inline-size` 안).
- 파일:
  - `src/data/packs.js` — 팩 레지스트리(토큰·템플릿 목록)
  - `src/components/packs/<pack>.jsx` — 그 팩의 템플릿 컴포넌트들 (절대배치)
- **렌더**: 카드 루트 `.card-canvas`(4:5, container-type) + 팩 토큰을 style 변수로 주입 → 템플릿이 `var(--card-*)` 사용.
- **확인용**: `?pack=mint` 로 `PackPreview`에서 그 팩 템플릿 전부 렌더 (본앱 플로우 안 건드림).
- **다음 연결**: 팩 → 생성기/편집기 (팩 선택 → 그 팩 템플릿·톤으로 시안). sky(1:1)는 비율 지원 붙일 때.
- **추가 방법**: 새 디자인 실측 → `packs.js`에 토큰 + `packs/<pack>.jsx`에 템플릿 추가 → 끝.
